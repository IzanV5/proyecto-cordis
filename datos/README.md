# Datos

Los dos Excel del profesor van aquí:

- `projects.xlsx`
- `SciVocCodes.xlsx`

Se han copiado desde la carpeta `H2020` del ordenador. Los originales siguen allí.
Los Excel quedan excluidos de GitHub. Cada compañero debe poner su propia copia
en esta carpeta después de descargar el repositorio.

`cache/` se crea al guardar los vectores. También queda fuera de GitHub.
Para generar TF-IDF y Word2Vec, ejecutar el cuaderno 1. Para BERT, el cuaderno 3.
Si compartimos una caché entre compañeros, debe proceder del mismo reparto y de
los mismos datos; las funciones comprueban que el contenido y el orden coinciden.

Si se cambia el preprocesamiento o los parámetros de una representación, hay que
volver a generar sus vectores antes de comparar resultados.
